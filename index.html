Privacy Policy — Odoo Quick Timesheet

Last updated: 2026-10-28

Odoo Quick Timesheet is a browser extension that helps users of an Odoo instance log timesheet entries and export project reports. This policy describes what the extension actually does.

What the extension does

The extension does nothing until the user clicks its toolbar icon. It then runs on the currently open tab only (Chrome activeTab permission) and shows a panel inside the Odoo page.

Data the extension reads

The panel communicates only with the Odoo server that hosts the open page, using that page's existing session (same-origin requests to /web/dataset/call_kw and /web/session/get_session_info). It reads:

  • projects and tasks (names, budgets/planned hours),
  • timesheet entries (employee name, date, hours, description, start/end time, work type, work location, vehicle, license, linked sales order and order line),
  • the current user's session information and public holidays/leaves needed for the time-entry forms.

Data the extension writes

Timesheet entries are created in Odoo (account.analytic.line) only when the user explicitly submits the manual-entry form or confirms the copy dialog. The extension does not edit or delete existing Odoo records.

Data stored locally

The extension stores its settings in the browser's localStorage of the Odoo site (not in any account or cloud):

  • visible projects and preferred default values (record IDs),
  • task budget values entered by the user,
  • report export layout (format, language, sheets, columns and their order).

Clearing the site data for the Odoo domain removes these settings.

Reports

XLSX and PDF reports are generated locally in the browser and saved to the user's device through the browser's download mechanism. Report content is not uploaded anywhere.

Third parties

The extension does not send any data to the developer or to any third party. It contains no analytics, telemetry, advertising or tracking. The only network requests are to the Odoo server of the open page and to the extension's own bundled logo file. Data is not sold or shared.

Remote code

The extension does not load or execute remote code. All code is bundled in the package. It does not use eval, new Function or externally hosted scripts.

Permissions

  • activeTab — temporary access to the tab where the user clicked the icon.
  • scripting — injecting the bundled panel script into that tab.

The extension requests no host permissions.
